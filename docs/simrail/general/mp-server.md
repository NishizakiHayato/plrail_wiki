- INT6 (International, Asia)

- PL3 (Polski) [BEZ WYDARZEŃ]
- PL5 (Polski) [TYMCZASOWY ROZKŁAD JAZDY]

- Xbox International 2
- Xbox Polski 1

:::tip

**INT9** 是测试和练习用服务器，不受技术规程限制，推荐新手在此服务器练手，同时该服务器也支持设置调车进路。

:::

:::danger

**DE1**、**INT1**、**PL3** 严格禁止事件、事故（整活），必须严格按照技术规程进行调度和驾驶，否则可能遭到封禁。
在其他非 INT9 的服务器上进行此类操作如果被人举报，也可能遭到封禁；如果需要进行活动，最好在 INT9 上进行。

:::

:::info

**INT6** 目前常态化处于关闭状态。

:::
