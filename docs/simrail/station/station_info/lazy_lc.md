## 位置

![瓦济 C 信号楼位置示意一](pathname:///img/simrail/station/station_info/lazy_lc/location-1.webp)

![瓦济 C 信号楼位置示意二](pathname:///img/simrail/station/station_info/lazy_lc/location-2.webp)

瓦济 C 信号楼是一个连接瓦济站的信号楼，信号楼可控制道岔将货物列车从宗布科维采、普热米亚尔基引向瓦济站的货运区，所有客运列车通过。

## 描述

::::::info

你需要**12小时**调度时长来解锁本站/

::::::

::::::info

**瓦济 C 信号楼**的难度为:★★★☆☆(3星)

::::::

### 特别事项

::::::warning

右侧通往Dąbrowa Górnicza Ząbkowice的方向设有三个乘降所，在道岔限速图中以蓝色标注。这些乘降所的站台仅设于1道、2道、4道，而3道未设站台，因此务必避免将406xx次列车经3道开往Ząbkowice。

左侧通往Łazy的线路存在类似情况：北上的S1/S41次列车可经由2道或4道运行，从而接入Łazy的站台。请勿将S1/S41次列车经6道运行——该路径无法抵达Łazy站台。
